# Frontend

Simple React dashboard for viewing websocket messages, connection status, and live updates from the backend.

## Run

```bash
npm install
npm start
```

Frontend runs on:

```
http://localhost:3000
```

## Features

- Live websocket connection status
- Send messages from UI
- View received messages in real time
- Auto reconnect handling
- Counter order verification
- Reset messages

## Usage

1. Run the frontend
2. Open browser on `http://localhost:3000`
3. Click `⚡ Send 30 messages`
4. Watch live updates in the dashboard

## Status Indicators

- 🟢 Online
- 🟡 Sending
- 🔴 Offline
